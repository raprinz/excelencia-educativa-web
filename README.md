# EdTech Navigator

PROYECTO: PORTAL CORPORATIVO Y COMERCIAL DE EXCELENCIA EDUCATIVA

Contexto del Proyecto

Desarrollar un sitio web corporativo moderno, elegante, responsivo y altamente escalable para la empresa Excelencia Educativa, una editorial colombiana especializada en la creación, comercialización y distribución de libros educativos para instituciones educativas públicas y privadas.

La empresa ofrece libros para diferentes niveles educativos, principalmente preescolar, transición, primaria y algunos grados de secundaria. Además de comercializar libros de otras editoriales, Excelencia Educativa desarrolla contenidos propios y se encuentra en un proceso de transformación digital para ofrecer una experiencia educativa innovadora.

El portal web no debe verse como una página tradicional de una editorial. Debe proyectar a Excelencia Educativa como una empresa EdTech (Educational Technology), donde la educación, la tecnología y la innovación se integran en un solo ecosistema.

No crear logotipo. La empresa ya cuenta con identidad visual.

Objetivo General

Construir el portal principal del ecosistema digital de Excelencia Educativa, permitiendo fortalecer su presencia institucional, mejorar la experiencia comercial, facilitar el contacto con instituciones educativas y servir como punto de acceso a futuras plataformas digitales.
